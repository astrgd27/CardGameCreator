# Generation Wars reference audit

Reference: Riftbound Core Rules revision 2026-10-09, rules 103, 417 and 431; https://riftbound.leagueoflegends.com/en-us/news/rules-and-releases/gameplay-guide-core-rules/ and https://riftbound.gg/rules/core-rules/.

Implemented in this batch: twelve-card shuffled rune decks, two initial/turn channels, second-seat bonus, independent exhaust and recycle generators. Automatic recycling is disabled for Generation Wars. Remaining: distinct domain power costs and identities, resource clearing at each timing boundary, true base and champion zones, move-initiated simultaneous combat, scoring cap/final point, legend and deck restrictions, burnout, accurate opening and mulligan rules. Do not claim full compatibility.
